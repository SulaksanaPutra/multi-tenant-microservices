Multi-Tenant Microservices Flow Demonstration

This is a minimal, unstyled UI to test and demonstrate the end-to-end multi-tenant workflow via Traefik Gateway (port 8000).

Step 1: Register Tenant (Control Plane)

Submits POST /api/register to tenant-service via Traefik Gateway.









Response Output:

(Awaiting submission...)

Step 2: Create Order (Data Plane)

Submits POST /api/orders with header X-Tenant-ID to order-service via Traefik Gateway.

Note: If you just registered a new tenant, allow 1–2 seconds for background provisioning (RabbitMQ + schema/container migration) before creating orders.









Response Output:

(Awaiting submission...)

Step 3: Fetch Tenant Orders (Data Plane)

Submits GET /api/orders with header X-Tenant-ID to order-service via Traefik Gateway.
